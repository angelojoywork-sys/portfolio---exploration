# Angelo's creative world

Portfolio landing page: pick one of six hand-drawn "Angelo" characters (Visual Designer, UX Designer, Design Engineer, Motion Designer, Video Editor, Photographer).

Plain HTML/CSS/JS, no build step.

    python3 -m http.server 8000   # then open http://localhost:8000

Deep links: `#visual`, `#ux`, `#engineer`, `#motion`, `#video`, `#photo`. Deploy by serving the folder as static files.
